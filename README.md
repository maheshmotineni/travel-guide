# Travel Guide

An AI-powered Travel Guide web application that provides historical information and generates multilingual audio guides for tourist places.

## Features

- Search for tourist places
- Generate historical information
- Generate AI-powered audio guides
- Multilingual support
- Voice selection
- Text transcript
- Summary and detailed information

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Google Gemini AI
- Murf AI
